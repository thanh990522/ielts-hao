# IELTS Hào

Interactive IELTS Foundation 1 learning website.

- **Teacher:** Hà Chí Thanh
- **Aim:** IELTS 6.0+
- **Stage:** Foundation 1
- **Lessons:** 6 x 90-minute lessons

## Learning structure

Each lesson contains:

1. **Theory** – concise visual lesson notes extracted and organised from the uploaded worksheet.
2. **Practice** – core worksheet activities.
3. **Inline answers** – every task has its own **Show answer** button directly below the question. Answers stay hidden until the student clicks.
4. **Extra Practice** – additional practice from the worksheet, including referenced online listening resources where applicable.
5. **Homework** – lesson-specific checklist.
6. **Progress tracking** – task/homework completion is stored locally in the learner's browser.

## Files

- `index.html` – complete responsive UI and lesson engine.
- `data/lesson-1.js` … `data/lesson-6.js` – lesson content, tasks, inline keys, explanations and homework.
- `.github/workflows/pages.yml` – GitHub Pages deployment.

## Deployment

The repository is configured to deploy to GitHub Pages after pushes to `main`.
